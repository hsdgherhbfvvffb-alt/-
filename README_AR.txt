ZIAD HOST - تشغيل محلي

1) ثبّت Python.
2) افتح المجلد في الطرفية ثم نفّذ:
   pip install -r requirements.txt
   python server.py
3) افتح الرابط الذي يظهر، غالباً:
   http://127.0.0.1:5000

في أول تشغيل سيظهر اسم المستخدم admin وكلمة مرور عشوائية في نافذة الطرفية.
احفظ كلمة المرور؛ لن تُعرض مرة أخرى. كلمة المرور محفوظة في قاعدة البيانات كـ hash
وليست داخل ملفات HTML أو JavaScript.

Termux:
   pkg update
   pkg install python
   cd إلى مجلد ziad_host
   pip install -r requirements.txt
   python server.py

الملفات:
templates/login.html       صفحة الدخول والتسجيل
templates/index.html       لوحة المستخدم والسيرفرات
templates/admin_panel.html لوحة المسؤول
server.py                  خادم Flask وواجهات API
data/                      قاعدة البيانات وملفات السيرفرات التي تنشئها

مهم:
- هذه حزمة تشغيل محلية/تجريبية متكاملة للواجهات وعمليات الملفات الأساسية.
- تشغيل مشاريع Python/Node يتم على نفس الجهاز الذي يشغل لوحة الاستضافة، وليس
  استضافة سحابية عامة. لا تعرض الخادم للإنترنت مباشرة.
- لا ترفع ملفات مجهولة أو غير موثوقة؛ ملفات التشغيل تنفذ أوامر على الجهاز.
- لتغيير عنوان الربط استخدم HOST=0.0.0.0 عند الحاجة داخل شبكة موثوقة فقط.


حل مشكلة "ملف التشغيل غير موجود":
- ارفع ملفات مشروعك داخل الخادم، أو ارفع ملف ZIP ثم استخدم زر فك الضغط.
- عند الضغط على تشغيل، يحاول النظام اكتشاف main.py أو app.py أو bot.py أو run.py تلقائياً (ولمشاريع Node: index.js أو app.js أو server.js).
- إذا كان اسم الملف مختلفاً، افتح إعدادات الخادم واختر ملف .py أو .js الصحيح من قائمة ملف بدء التشغيل.
- تأكد أن ملف التشغيل موجود فعلاً داخل مجلد ملفات الخادم.


تحديث إصلاح التشغيل التلقائي: إذا كان اسم ملف بدء التشغيل المحفوظ قديماً مثل main.py وغير موجود، سيبحث النظام عن ملف Python الموجود مثل pind_tool.py ويستخدمه تلقائياً.


تشغيل أي ملف Python:
- لم يعد التشغيل مرتبطاً بأسماء main.py أو app.py أو bot.py.
- أي ملف امتداده .py داخل مجلد الخادم أو مجلد فرعي يمكن تشغيله مهما كان اسمه.
- عند عدم وجود اختيار سابق صالح، يختار النظام أول ملف .py تلقائياً.
- ملفات مثل requirements.txt و JSON ليست ملفات تشغيل؛ يتم استخدامها كملفات إعداد/اعتماديات.
